📱 Simulador de Coletor Zebra - Treinamento de PickingUm simulador web responsivo que replica a interface em fósforo verde (tela caractere/telnet/WMS) de um coletor de dados portátil Zebra/Motorola utilizado em armazéns e centros de distribuição para operações de separação de pedidos (picking).🚀 Demonstração OnlineAcesse o simulador diretamente pelo navegador via GitHub Pages:👉 Ver Simulador em Execução🎯 Objetivo do ProjetoCapacitar operadores de logística e separadores de pedidos no manuseio de coletores móveis em processos de WMS, praticando:Identificação de endereço logístico e código de produto.Conferência visual com miniatura do item.Validação por código de barras (bipagem ou digitação manual).Controle de quantidade solicitada versus quantidade separada.Navegação entre itens de uma ordem de separação.✨ FuncionalidadesVisual Realista: Estilo clássico de terminal WMS/Telnet (fundo preto com caracteres verdes fosforescentes).Leitor de Código de Barras Integrado: Campo de entrada com validação instantânea via tecla Enter (compatível com leitores ópticos USB/Bluetooth ou digitação).Validação de Separação:Incremento automático da quantidade ao bipar o item correto.Alerta de erro visual em caso de bip incorreto (CÓDIGO INVÁLIDO!).Sinalização de conclusão (ITEM FINALIZADO!) ao atingir o volume solicitado.Exibição de Miniaturas: Suporte a imagens compactas e centralizadas para apoio à conferência do item.Navegação de Itens: Botões de avanço e retorno para navegar pelas linhas do pedido.Relógio de Status: Exibição dinâmica de horário e indicadores fictícios de conectividade (Wi-Fi, Bluetooth e Bateria).📦 Itens Simulados no TreinamentoCódigo do ProdutoDescriçãoQtd.Código de Barras (EAN)02.20N.035.01.0000BARRA CEREAIS KOBBER478900000000101.10A.012.02.1234BISCOITO RECHEADO
